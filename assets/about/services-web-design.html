Design

Web Design

Structure and interface that make a site feel like an extension of the strategy behind it.

You're looking at one example right now — this site is built the way I'd build any client's: flagship work gets room to be read in full, lighter projects don't pretend to be flagships, and each service gets a specific answer instead of a paragraph buried in a long page. The same principle built magnaite.com from scratch — a Saudi B2B systems-integration brand that needed to read as trustworthy in a two-minute skim, structured so the case for the company argues itself before a single line of copy does.

magnaite.com ↗

What's included in web design work?

The structure of the site, the words on it, the visual design, and the search foundations underneath.

  • Site structure. Which pages exist, what each one is for, and the path a visitor takes from landing to contacting you.
  • Page-by-page messaging. What each page has to prove, in what order.
  • Copy in English and Arabic. Written for the site, not pasted in from a brochure. I wrote website copy for the Egypt Retail Summit.
  • Visual design. Layouts that follow the structure, so the design supports the argument instead of decorating it.
  • SEO foundations. Clean page structure, titles and descriptions, and a keyword mapped to each page from launch. See SEO.
  • Answer-ready content. FAQs and question-led headings, so AI assistants can read the site clearly. See GEO.

How do you work on a website?

I plan the structure and write the copy myself. A supervised team works on the visual design.

I start with the case the site has to make. For Magnaite, that was a Saudi B2B systems integrator that needed to read as trustworthy to a decision-maker skimming for two minutes. Every page decision followed from that.

Then I outline the pages and draft the copy before anything is designed. Design built on real words looks different from design built on placeholder text, and it usually works better.

When the design comes back, I review every page against the structure and the copy. Before launch I check it on a phone and a desktop, test the forms, and confirm the search basics are in place. Nothing goes live until it passes.

We agree up front what the site is for, so we know what to measure once it's live: enquiries, sign-ups, or whatever action matters to you.

Who is web design for?

It suits a few situations.

  • A company whose website no longer describes what it does today.
  • A B2B company whose buyers check the site before a meeting and leave unconvinced.
  • A brand launching in a new market that needs Arabic and English pages that both read properly.
  • A business that needs to be found in search and in AI answers, and wants that built in from the start.

What do you get first?

For a new site, a page map and the core messaging. For an existing one, an audit.

The page map shows every page, its purpose and its main message, so you can approve the structure before design starts. The audit lists what's working, what isn't and what to fix first. That's where my work with Appana Technologies in Dubai began: a website audit with recommendations.

Questions people ask

Do you redesign existing websites?

Yes. Redesigns usually start with an audit of the current site, so we keep what works and fix what doesn't.

Can you build a bilingual website in English and Arabic?

Yes. I write both languages myself and plan the Arabic pages for Arabic readers, not as a translation.

Can you work with a developer I already have?

Yes. I can own the structure, copy and design direction, hand them to your developer, and review the build before it goes live.

Is SEO included in web design?

The foundations are. Page structure, titles, descriptions and keyword mapping are built in from launch. Ongoing SEO is a separate service.
